\# ⚡ EV Market Performance and Insights



An interactive data visualization and web integration project that explores electric vehicle (EV) market trends, manufacturer benchmarks, battery chemistry mixes, adoption metrics, and regional performance distributions.



The project uses \*\*Tableau Public\*\* (featuring both an interactive Dashboard and a guided Story) embedded within a custom \*\*Flask\*\* web application hosted on \*\*Render\*\*, helping users explore electric vehicle market intelligence seamlessly.



\## 📊 Project Overview



The electric vehicle (EV) market is evolving rapidly, driven by technological innovations, scaling manufacturing hubs, and changing consumer preferences. Understanding these dynamic variations through static tables or isolated reports can be challenging.



This project provides an integrated web platform and interactive Tableau dashboard for exploring key EV market metrics, making it easier to compare manufacturers, analyze battery technology distributions, investigate vehicle categories, and understand broader mobility patterns.

\## ✨ Key Features



\* \*\*Manufacturer Performance Benchmarks:\*\* Compare revenue, unit sales, and market positioning across leading brands (e.g., AmpereWorks, CircuitWorks, MomentumMobility, SurgeDynamics).

\* \*\*Battery Chemistry Mix Analysis:\*\* Investigate market share breakdowns across power cells including LFP, NMC, NCA, and emerging Sodium-Ion technologies.

\* \*\*Vehicle Category Segmentation:\*\* Explore trends across hatchbacks, micro city cars, sedans, compact SUVs, luxury SUVs, and pickup trucks.

\* \*\*Geographic \& Regional Distribution:\*\* Track regional production hubs, country-wise distribution, and localized adoption growth rates.

\* \*\*Range \& Capacity Metrics:\*\* Review driving range benchmarks and average battery pack capacities.

\* \*\*Customer Satisfaction Tracking:\*\* Analyze aggregated satisfaction ratings cross-referenced against vehicle types and manufacturers.

\* \*\*Guided Narrative Story:\*\* Follow a structured visual sequence communicating key market growth insights.

\* \*\*Interactive Web Experience:\*\* Access all analytical components through a modern, glassmorphic dark-themed web application.

\## 📈 Dashboard Objectives



The dashboard and web platform are designed to help users:



1\. Compare unit sales, revenues, and performance metrics across major EV manufacturers.

2\. Explore market adoption trends and category-wise segmentation.

3\. Identify battery technology preferences and efficiency benchmarks.

4\. Review customer satisfaction scores and driving range capabilities.

5\. Communicate data-driven observations through integrated interactive visualizations.
